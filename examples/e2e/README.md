# E2E smoke

Все подключения направлены только на loopback. Python 3.11+, сторонних Python-пакетов и curl не нужно.

## Автоматический режим

Из корня репозитория:

```bash
cargo build --locked --release
python3 examples/e2e/drive.py --binary target/release/minotaur
```

Драйвер создаёт временный TOML, запускает бинарник на портах `127.0.0.1:0`,
читает объявленные адреса, проверяет SSH/HTTP/Telnet/raw, метрики и JSONL stdout.
Затем оставляет активную SSH-сессию, отправляет SIGTERM и требует запись
`close_reason=shutdown` и код завершения 0. Порты не выбираются с последующим
освобождением. Временные процессы завершаются и при ошибках теста.

Проверяются отсутствие тела у HEAD, три Telnet-попытки одним потоком,
subnegotiation с переводом строки, 12 байт raw-данных, schema_version=2,
назначенные ОС dst_port и отсутствие тестового секрета в metadata-логах.
Автоматический SIGTERM-режим предназначен для POSIX. Это тестовая утилита,
не production-клиент и не генератор нагрузки.

## Ручной режим

Первый терминал, из корня репозитория:

```bash
./target/release/minotaur -c examples/e2e/minotaur.toml run
```

Второй терминал:

```bash
python3 examples/e2e/drive.py
```

Лог: `examples/e2e/honeypot.jsonl`, а не файл в текущем каталоге.
Ручной режим проверяет сетевые ответы и метрики; содержимое файла и SIGTERM
автоматически проверяются только режимом `--binary`.

Драйвер возвращает ненулевой код при ошибке, не полагается на границы TCP-пакетов
и сохраняет остаток прочитанного между ожиданиями prompts. Повторный ручной
запуск добавляет записи; число строк в существующем файле не обязано быть равно четырём.
